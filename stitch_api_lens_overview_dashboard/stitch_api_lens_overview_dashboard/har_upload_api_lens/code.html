What is a HAR file?

A HAR (HTTP Archive) records complete browser interaction data, documenting headers, cookies, payloads, and response codes.

Chrome DevTools → Network tab → Right Click → “Save all as HAR with content”

Privacy Notice

Network archives often preserve sensitive bearer tokens, session identifiers, and payload credentials. API Lens processes all schemas, request streams, and status logs strictly within memory in your local browser sandbox.
